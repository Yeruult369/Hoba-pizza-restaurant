HOBA PIZZA — СУРГАЛТЫН ТӨСЛИЙН ВЕБСАЙТ (Монгол хэлээр)

1. ZIP файлыг Extract All хийнэ.
2. HOBA_Pizza_Website хавтсыг Visual Studio Code-д File > Open Folder сонгоод нээнэ.
3. index.html дээр хоёр дарж Chrome-д нээх эсвэл VS Code Live Server extension-ээр Open with Live Server хийнэ.
4. Интернэтгүй үед нүүр, цэс, зургууд, animation, хайлт, favorites зэрэг ажиллана. Google Maps болон Instagram гадаад холбоосуудад интернэт хэрэгтэй.

ХУУДАСНУУД
index.html — Нүүр
menu.html — Пицца, бургер, cheese melts, амттан, ундаа; шүүх/хайх/хэмжээ солих
about.html — Рестораны танилцуулга
gallery.html — AI concept зурагнууд
visit.html — Байршил, холбоо барих
content-plan.html — Problem Set 2 маркетинг, 12 Reels, календарь
interview.html — Менежер/ажилтны interview асуултын хоосон загвар
assets/style.css — Дизайн, хөдөлгөөн
assets/app.js — Menu filter, select size, favorites, mobile nav
assets/*.webp — AI-ээр үүсгэсэн хоолны concept зургууд (офлайн ажиллана)

АНХААРАХ
Энэ бол HOBA-ийн албан ёсны баталгаат вэбсайт биш, сургалтын зориулалттай загвар.
Меню ба үнэ нь олон нийтэд нийтлэгдсэн фото мэдээлэлд тулгуурласан бөгөөд хуучирсан байж болно. Бодит үнээ ресторанаас баталгаажуул.
AI зургууд нь хоолны бодит гэрэл зураг БИШ; рестораны зөвшөөрсөн жинхэнэ зургаар солино.
+ товч нь сонирхсон жагсаалтад нэмдэг, жинхэнэ захиалга биш.
